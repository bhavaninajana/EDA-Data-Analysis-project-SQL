#  Custoner Sales Data Exploratory Data Analysis (SQL

## 📊 Project Overview
This project performs Exploratory Data Analysis (EDA) on a sales dataset
using SQL to uncover trends, patterns, and business insights.

## 🎯 Objective
To analyze sales performance, customer behavior, and product trends to support data-driven decision-making.

## 🛠 Tools Used
- SQL (SQL Server)
- Aggregate Functions
- Joins, Subqueries, CTEs
- Window Functions

## 🔎 Key Analysis Performed
- Monthly,Yearly sales trend analysis
- Find the distribution of sold items across countries
- Top 5 products generate the highest revenue
- Calculated the total sales per month and the running total of sales over time

## 📈 Key Insights
- Identified top-performing products using ranking window functions.
- Total revenue generated by each customer 
## ✅ Conclusion
The analysis provided valuable insights into seasonal trends, regional performance, and product demand, helping identify opportunities for revenue growth and strategic planning.
